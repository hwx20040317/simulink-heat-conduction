## 瞬态基准

两个热容量：C1=1000 J/K、C2=500 J/K；初始温度：40 ℃、20 ℃；连接热阻 R=0.8 K/W；无外部热流。

```text
Teq = (C1*T10+C2*T20)/(C1+C2) = 33.3333333333 degC
deltaT(t) = (T10-T20)*exp(-t*(1/C1+1/C2)/R)
T1(t) = Teq+C2/(C1+C2)*deltaT(t)
T2(t) = Teq-C1/(C1+C2)*deltaT(t)
```

普通离散积分器，固定步长 0.01 s，计算至 200 s：

- 与解析解相比的最大绝对温差：`8.8570320286862625e-5` ℃。
- `C1*T1+C2*T2` 的最大相对变化：`9.0221874415874481e-15`。
- 后者用于检查这个封闭、常热容量算例的能量守恒；解析解对照同时检查时间积分误差。
